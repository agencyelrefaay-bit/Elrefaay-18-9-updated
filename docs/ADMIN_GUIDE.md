# دليل المدير (Admin Guide)

## إدارة المستخدمين

- إنشاء مستخدم: شاشة المستخدمين (admin فقط) → اسم مستخدم + باسورد + دور
- الأدوار المتاحة وصلاحياتها بالتفصيل: شوف الجدول في `docs/USER_GUIDE_AR.md`
- تعطيل مستخدم بدل حذفه لو ترك الشركة (يحافظ على سجل العمليات القديمة
  المرتبطة باسمه — الحذف الفعلي ممكن يكسر مراجع تاريخية)
- `can_view_cost_price`: صلاحية منفصلة تتحكم هل المستخدم يشوف سعر
  التكلفة (مهمة لموظفي المبيعات اللي ملهمش داعي يشوفوا هامش الربح)

## مصفوفة الصلاحيات (مرجع سريع)

| الإجراء | admin | manager | sales | warehouse |
|---|:---:|:---:|:---:|:---:|

| التقارير المالية الكاملة | ✅ | ✅ | ❌ | ❌ |

`router.post(..., authorize(...), ...)` أعلى كل ملف في `src/routes/`)

## الإعدادات العامة

شاشة الإعدادات (admin فقط) بتتحكم في:
- تفعيل/تعطيل الإشعارات (`notifications_enabled`)
- عدد أيام التذكير بالأقساط قبل الاستحقاق
- تفعيل تنبيه نقص المخزون

## مراجعة سجل التدقيق (Audit Log)

كل عملية حساسة (تسجيل دخول فاشل، إنشاء/تعديل/إلغاء) بتتسجل في جدول
`audit_log` مع المستخدم والوقت والتفاصيل. للاستعلام المباشر:
```sql
SELECT u.username, a.action, a.entity_type, a.created_at
FROM audit_log a JOIN users u ON a.user_id = u.id
ORDER BY a.created_at DESC LIMIT 50;
```

## أمان — مسؤوليات دورية

- تغيير كلمة مرور admin الافتراضية فورًا بعد أول تشغيل
- مراجعة `audit_log` بشكل دوري بحثًا عن أنماط `login_failed` متكررة
  (مؤشر محتمل لمحاولة اختراق)
- التأكد من تنفيذ النسخ الاحتياطي فعليًا (مش بس "مجدول" — شوف
  `deploy/BACKUP_GUIDE.md` لطريقة التحقق)
